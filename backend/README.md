# NIYAMNETRA AI backend

Express services for OCR, extraction, rules, AI explanation, and reports will be added in later phases.

Reserved layout:

- `routes/` `controllers/` `services/`
- `ocr/` `extraction/` `rules/` `ai/` `reports/`
- `models/` `middleware/` `config/`
- `data/rules/` — configurable rule JSON (seeded in Phase 1)

Phase 1 does not start an API server. The React app runs on mock screening data.
